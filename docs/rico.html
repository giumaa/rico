  2. افتح الملف. لو طلعتلك شاشة زرقا «Windows protected your PC»، اضغط More info وبعدين Run anyway.
  3. كمّل التثبيت وافتح ريكو، واختار النموذج اللي يناسب الرام في جهازك (مكتوب على كل بطاقة).

  1. Download Rico-Setup-0.4.0-x64.exe. If the browser says the file isn't commonly downloaded, click ⋯ → Keep.
  2. Open it. If a blue "Windows protected your PC" screen appears, click More info → Run anyway.
  3. Finish the installer, open Rico and pick the model that matches your RAM (shown on each card).
  4. Let the one-time download finish — after that Rico works offline.
